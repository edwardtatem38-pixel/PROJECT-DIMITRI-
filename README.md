# PROJECT-DIMITRI-
[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/drive/1Yf9FL5ZyHHmqW71lY24ndfhmrMaF7Zzo?usp=sharing)
Dimitri is a specialized Large Language Model (Llama-3 8B) fine-tuned using Unsloth and LoRA to interpret SMILES chemical notation. It translates molecular structures into detailed reports on botanical origins, biochemical pathways (like NF-kappaB inhibition), and pharmacological properties. Features a custom 8-bit Gradio/IPyWidgets
